# Groups

## The `Group` class

A finite group in GroupMaker is represented by an instance of the `Group` class.

Mathematically, a group is a pair $(G,\ast)$, where $G$ is a set and $\ast$ is a binary operation satisfying associativity, the existence of an identity element, and the existence of inverses.

In GroupMaker, these mathematical objects are represented computationally by `Group` objects.

---

## Creating a group

A group can be created using the `Group` constructor. To create a group, its Cayley table is required; this is a matrix that defines how its elements operate with one another. The default names for the elements are the integers $0, 1, \dots, n-1$, where $n$ is the order of the group.

```python
from groupmaker import *

G = Group(table)
```

For example:

```python
G = Group([[0, 1], [1, 0]])
```

If you want to view the Cayley table matrix of a group `G`, you can write `G.cayley`:

```python
G.cayley        #[[0, 1], [1, 0]]
```

Once created, `G` can be used to access the properties and operations associated with the group.

---

## Renaming elements

As mentioned, the default names for the elements are $0, 1, \dots, n-1$. To use custom names in a group, you can pass a list containing them when defining the group:

```python
G = Group([[0, 1], [1, 0]], names=["a", "b"])
```

Mathematically, this group is identical to `G = Group([[0, 1], [1, 0]])`, but the element `0` is now named `"a"` and the element `1` is now named `"b"`. However, writing `G.cayley` will still return `[[0, 1], [1, 0]]`. By writing `G.names`, you will obtain the list of element names:

```python
G.names     # ["a", "b"]
```

To see the Cayley table matrix with the names of the elements, use `print(G)`.
```python
print(G)    # [["a", "b"], ["b", "a"]]
```

---

## Order of a group

The order of a finite group $G$, denoted by $|G|$, is the number of elements in $G$. In GroupMaker, the order can be obtained using:

```python
G.order()
```

For example, if `S3` represents the symmetric group of degree 3:

```python
S3.order()      # 6
```

---

## Cayley table

The Cayley table describes the result of the group operation for every pair of elements in $G$. It can be displayed using:

```python
G.cayley_table()
```

The output is an image generated by `matplotlib.pyplot`. For example, with `S3`:

![S3 table](https://raw.githubusercontent.com/MarioSultan/GroupMaker/main/imgs/cayley_S3.png)

The elements rendered by `matplotlib.pyplot` in the Cayley table correspond exactly to `S3.names`.

## Related functionality

The `Group` class also provides methods for studying properties such as:

* Cyclicity: 

```python
S3.is_cyclic()      # False
```

* Commutativity:

```python
S3.is_abelian()     # False
```

* Subgroups:

```python
for i in S3.subgroups():
    print(i)

"""
[['e']]
[['e', '(23)'], ['(23)', 'e']]
[['e', '(12)'], ['(12)', 'e']]
[['e', '(13)'], ['(13)', 'e']]
[['e', '(123)', '(132)'], ['(123)', '(132)', 'e'], ['(132)', 'e', '(123)']]
[['e', '(23)', '(12)', '(123)', '(132)', '(13)'], ['(23)', 'e', '(132)', '(13)', '(12)', '(123)'], ['(12)', '(123)', 'e', '(23)', '(13)', '(132)'], ['(123)', '(12)', '(13)', '(132)', 'e', '(23)'], ['(132)', '(13)', '(23)', 'e', '(123)', '(12)'], ['(13)', '(132)', '(123)', '(12)', '(23)', 'e']]
"""
```

* Proper subgroups:

```python
for i in S3.proper_subgroups():
    print(i)

"""
[['e', '(23)'], ['(23)', 'e']]
[['e', '(12)'], ['(12)', 'e']]
[['e', '(13)'], ['(13)', 'e']]
[['e', '(123)', '(132)'], ['(123)', '(132)', 'e'], ['(132)', 'e', '(123)']]
"""
```

* Center:

```python
S3.center()     # [0]
```
