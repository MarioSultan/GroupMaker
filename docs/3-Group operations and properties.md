# Group operations and properties

Once a group has been created, either manually or by using one of the available group families, GroupMaker provides several methods for studying its algebraic structure.

The examples below use the precooked groups included in the library, but the same methods can be applied to any instance of the `Group` class.

```python
from groupmaker.precooked import *
```

---

## Identity element

The identity element of a group $G$ can be obtained using:

```python
G.identity()
```

The method returns the internal index of the identity element.

For example:

```python
S3.identity()     # 0
```

Since the identity corresponds to an element of `G.names`, its displayed name can be obtained with:

```python
S3.names[S3.identity()]     # 'e'
```

---

## Orders of elements

The order of an element $g \in G$ is the smallest positive integer $n$ such that $g^n=e$. The orders of all elements of a group can be obtained using:

```python
G.element_orders()
```

The returned list follows the same order as `G.names`.

For example:

```python
S3.names
# ['e', '(23)', '(12)', '(123)', '(132)', '(13)']

S3.element_orders()
# [1, 2, 2, 3, 3, 2]
```

Therefore, the identity has order $1$, the transpositions have order $2$, and the $3$-cycles have order $3$.

---

## Distribution of element orders

The distribution of element orders can be obtained using:

```python
G.order_distribution()
```

This returns a dictionary whose keys are possible element orders and whose values indicate how many elements have each order.

For example:

```python
S3.order_distribution()
# {1: 1, 2: 3, 3: 2}
```

Thus, $S_3$ contains one element of order $1$, three elements of order $2$, and two elements of order $3$.

---

## Cyclic groups

A group is cyclic if it can be generated by a single element. In GroupMaker, this property can be checked using:

```python
G.is_cyclic()
```

For example:

```python
C6.is_cyclic()     # True
V4.is_cyclic()     # False
```

---

## Abelian groups

A group is abelian if $ab=ba$ for every pair of elements $a,b \in G$.

This can be checked using:

```python
G.is_abelian()
```

For example:

```python
C6.is_abelian()    # True
S3.is_abelian()    # False
```

---

## The center of a group

The center of a group $G$, denoted by $Z(G)$, is the set of elements that commute with every element of the group:

$$
Z(G)=\{z\in G\mid zg=gz\text{ for every }g\in G\}.
$$

In GroupMaker, the center can be obtained using:

```python
G.center()
```

The method returns the internal indices of the elements belonging to the center. For example:

```python
Q8.center()        # [0, 1]
```

The corresponding element names are:

```python
[Q8.names[i] for i in Q8.center()]
# ['1', '-1']
```

---

## Subgroups

All subgroups of a group can be obtained using:

```python
G.subgroups()
```

This includes the trivial subgroup and the group itself.

For example:

```python
S3.subgroups()
```

To obtain only the proper subgroups, use:

```python
G.proper_subgroups()
```

For example:

```python
for H in S3.proper_subgroups():
    print(H)
```

GroupMaker also provides a method for obtaining all normal subgroups:

```python
G.normal_subgroups()
```

For example:

```python
S3.normal_subgroups()
```

The returned objects can then be used for further operations with subgroups.

---

## Simple groups

A group is simple if its only normal subgroups are the trivial subgroup and the group itself.

This property can be checked using:

```python
G.is_simple()
```

For example:

```python
A5.is_simple()     # True
S3.is_simple()     # False
```

---

## Quotient groups

If $H$ is a normal subgroup of $G$, the quotient group $G/H$ can be constructed using:

```python
G.quotient(H)
```

For example:

```python
G = S3
H = G.normal_subgroups()[2]:
Q = G.quotient(H)
print(Q)
```

The quotient group can also be constructed using the `/` operator:

```python
Q = G / H
```

Both expressions produce the same quotient group.

The resulting object is an instance of the `Group` class and can therefore be studied using the usual methods:

```python
Q.order()
Q.is_cyclic()
Q.cayley_table()
```

---

## Automorphisms

An automorphism of a group $G$ is an isomorphism from $G$ to itself.

In GroupMaker, an automorphism is represented internally as a permutation of the indices of the elements. A candidate automorphism can be checked using:

```python
G.is_automorphism(phi)
```

For example:

```python
C4.is_automorphism((0, 3, 2, 1))
# True
```

All automorphisms of a group can be obtained using:

```python
G.automorphisms()
```

For example:

```python
C4.automorphisms()
# [(0, 1, 2, 3), (0, 3, 2, 1)]
```

Finally, the automorphism group $\text{Aut}(G)$ can be constructed using:

```python
G.automorphism_group()
```

The result is itself a `Group` object, so all the usual methods can be applied to it. For example:

```python
AutC4 = C4.automorphism_group()

AutC4.order()      # 2
AutC4.is_cyclic()  # True
```
