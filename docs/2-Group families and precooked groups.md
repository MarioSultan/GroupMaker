# Group families and precooked groups

In **GroupMaker**, besides creating generic groups by passing custom Cayley tables, you can directly instanciate well-known algebraic families of groups using constructor functions or by importing **precooked groups** directly available in the library.

---

## Group families (Constructor Functions)

GroupMaker provides helper functions to instantly build standard mathematical groups of arbitrary order or degree without manually entering Cayley tables.

### 1. Cyclic Groups: `cyclic_group(n)`

A cyclic group $C_n$ (or $\mathbb{Z}_n$) of order $n$ is generated by a single element $r$ such that $r^n = e$.

```python
from groupmaker import cyclic_group

# Create a cyclic group of order 5
C5 = cyclic_group(5)

print(C5.names)
# ['$e$', '$r$', '$r^{2}$', '$r^{3}$', '$r^{4}$']

C5.is_cyclic()  # True
C5.is_abelian() # True
```

---

### 2. Symmetric Groups: `symmetric_group(n)`

The symmetric group $S_n$ is the group of all permutations of $n$ symbols. Its order is $n!$.

```python
from groupmaker import symmetric_group

# Create the symmetric group S3 (degree 3, order 3! = 6)
S3 = symmetric_group(3)

print(S3.names)
# ['e', '(23)', '(12)', '(123)', '(132)', '(13)']

S3.order()     # 6
S3.is_abelian() # False
```

---

### 3. Alternating Groups: `alternating_group(n)`

The alternating group $A_n$ is the subgroup of $S_n$ consisting of all even permutations. Its order is $n! / 2$.

```python
from groupmaker import alternating_group

# Create the alternating group A4 (degree 4, order 4!/2 = 12)
A4 = alternating_group(4)

print(A4.names)
# ['e', '(234)', '(243)', '(12)(34)', '(123)', '(124)', '(132)', '(134)', '(13)(24)', '(142)', '(143)', '(14)(23)']

A4.order() # 12
```

---

### 4. Dihedral Groups: `dihedral_group(n)`

The dihedral group $D_n$ represents the symmetries of a regular $n$-sided polygon, including rotations $r$ and reflections $s$. Its order is $2n$.

```python
from groupmaker import dihedral_group

# Create the dihedral group D4 (order 2*4 = 8)
D4 = dihedral_group(4)

print(D4.names)
# ['$e$', '$r$', '$r^{2}$', '$r^{3}$', '$s$', '$rs$', '$r^{2}s$', '$r^{3}s$']

D4.order()     # 8
D4.is_abelian() # False
```

---

### 5. Multiplicative Group of Integers Modulo $n$: `units_group(n)`

The group $U(n)$ (or $(\mathbb{Z}/n\mathbb{Z})^\times$) consists of the integers coprime to $n$ under multiplication modulo $n$. Its order is given by Euler's totient function $\phi(n)$.

```python
from groupmaker import units_group

# Create the units group U(8)
U8 = units_group(8)

print(U8.names)
# ['1', '3', '5', '7']

U8.is_abelian() # True
```

---

### 6. Dicyclic / Generalized Quaternion Groups: `dicyclic_group(n)`

The dicyclic group $\text{Dic}_n$ is a non-abelian group of order $4n$. For $n = 2$, $\text{Dic}_2$ is isomorphic to the quaternion group $Q_8$.

```python
from groupmaker import dicyclic_group

# Create the dicyclic group Dic2 (order 8)
Dic2 = dicyclic_group(2)

print(Dic2.names)
# ['$e$', '$a$', '$a^{2}$', '$a^{3}$', '$x$', '$ax$', '$a^{2}x$', '$a^{3}x$']

Dic2.order() # 8
```

## Precooked Groups

GroupMaker comes with a rich set of pre-defined (`precooked`) group instances ready to use immediately upon importing the library. These instances save you from having to construct or instantiate standard groups manually.

### Importing Precooked Groups

You can import all precooked groups into your workspace:

```python
from groupmaker.precooked import *
```

### Available Precooked Groups List

| Family | Instances Available | Examples & Description |
| :--- | :--- | :--- |
| **Trivial Group** | `I` | The trivial group containing only the identity element `$e$`. |
| **Cyclic Groups** | `C1` through `C20` | `C5` represents $C_5$, with element names `['$e$', '$r$', '$r^{2}$', '$r^{3}$', '$r^{4}$']`. |
| **Symmetric Groups** | `S1`, `S2`, `S3`, `S4` | `S3` represents $S_3$ (order 6), `S4` represents $S_4$ (order 24). |
| **Alternating Groups** | `A1`, `A2`, `A3`, `A4` | `A4` represents $A_4$ (order 12) with cycle notation. |
| **Dihedral Groups** | `D1` through `D10` | `D4` represents $D_4$ (order 8) with elements `$e$, $r$, $s$, \dots$`. |
| **Units Groups Modulo $n$** | `U2` through `U20` | `U8` represents $U(8) = \{1, 3, 5, 7\}$, `U10` represents $U(10)$. |
| **Klein Four-Group** | `V4` | Klein 4-group with names `["e", "a", "b", "ab"]`. |
| **Quaternion Group** | `Q8` | Quaternion group of order 8 with names `["1", "-1", "i", "-i", "j", "-j", "k", "-k"]`. |
| **Dicyclic Groups** | `Dic2`, `Dic3` | Dicyclic groups of order $4n$ ($\text{Dic}_2$ has order 8, $\text{Dic}_3$ order 12). |

---

## Usage Examples with Precooked Groups

Since precooked groups are instances of the `Group` class, all standard methods and visual representations work out of the box:

```python
from groupmaker.precooked import Q8, V4, C4, D3

# Inspect Quaternion Group Q8
print("Q8 order:", Q8.order())           # 8
print("Q8 elements:", Q8.names)          # ['1', '-1', 'i', '-i', 'j', '-j', 'k', '-k']
print("Q8 Center:", Q8.center())         # [0, 1] , which are ['1', '-1']

# Compare Klein Four-Group V4 vs C4
print("Is V4 cyclic?", V4.is_cyclic())   # False
print("Is C4 cyclic?", C4.is_cyclic())   # True

# Display Cayley Table of D3
D3.cayley_table()
```
