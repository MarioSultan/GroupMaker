# Groups

## The `CayleyGroup` class

Mathematically, a group is a pair $(G,\ast)$, where $G$ is a set and $\ast$ is a binary operation satisfying associativity, the existence of an identity element, and the existence of inverses.

In GroupsMath, these mathematical objects are represented computationally by `CayleyGroup` objects.

---

## Creating a group

A group can be created using the `CayleyGroup` constructor. To create a `CayleyGroup`, its Cayley table is required; this is a matrix that defines how its elements operate with one another. The default names for the elements are the integers $0, 1, \dots, n-1$, where $n$ is the order of the group.

```python
from groupsmath import *

G = CayleyGroup(table)
```

For example:

```python
G = CayleyGroup([[0, 1], [1, 0]])
```

If you want to view the Cayley table matrix of a group `G`, you can write `G.cayley`:

```python
G.cayley        #[[0, 1], [1, 0]]
```

Once created, `G` can be used to access the properties and operations associated with the group.

---

## Renaming elements

As mentioned, the default names for the elements are $0, 1, \dots, n-1$. To use custom names in a group, you can pass a list containing them when defining the group:

```python
G = CayleyGroup([[0, 1], [1, 0]], elements=["a", "b"])
```

Mathematically, this group is identical to `G = CayleyGroup([[0, 1], [1, 0]])`, but the element `0` is now named `"a"` and the element `1` is now named `"b"`. However, writing `G.cayley` will still return `[[0, 1], [1, 0]]`. By writing `G.elements`, you will obtain the list of element names:

```python
G.elements     # ["a", "b"]
```

---

## Order of a group

The order of a finite group $G$, denoted by $|G|$, is the number of elements in $G$. In GroupsMath, the order can be obtained using:

```python
G.order()
```

For example, if `S3` represents the symmetric group of degree 3:

```python
S3.order()      # 6
```

---

## Cayley table

The Cayley table describes the result of the group operation for every pair of elements in $G$. It can be displayed using:

```python
G.cayley_table()
```

The output is an image generated by `matplotlib.pyplot`. For example, with `S3`:

![S3 table](https://raw.githubusercontent.com/MarioSultan/GroupsMath/main/imgs/cayley_S3.png)

The elements rendered by `matplotlib.pyplot` in the Cayley table correspond exactly to `S3.elements`.

## Related functionality

The `CayleyGroup` class also provides methods for studying properties such as:

* Cyclicity: 

```python
S3.is_cyclic()      # False
```

* Commutativity:

```python
S3.is_abelian()     # False
```

* Subgroups:

```python
for i in S3.subgroups():
    print(i)

"""
```

```python
for i in S3.proper_subgroups():
    print(i.cayley)
```

* Center:

```python

```

## The `ExplicitGroup` class

As said, a group is a pair $(G,\ast)$, where $G$ is a set and $\ast$ is a binary operation satisfying the axioms. If you know a little Python, you will be able to define a group using the `ExplicitGroup` class. Firstly, a list of elements and a function between them is defined, for example:

```python
my_elements = [0,1,2,3,4]

def modulo5(a,b):
    return (a+b)%5
```

Then, simply use the `ExplicitGroup` constructor to create a group by its definition:

```python
G = ExplicitGroup(my_elements, modulo5)
```

Its elements can be accessed by `G.elements` and the function via `G.function`.
The methods of the `CayleyGroup` class is the same as the `ExplicitGroup` class, such as `G.order()`, `G.subgroups`, `G.cayley_table()`, ...

Both classes, `CayleyGroup` and `ExplicitGroup` are instance of the father class `Group`.
```
                ┌────────── CayleyGroup
                │
Group ──────────┼────────── ExplicitGroup
                │
                └────────── ...
```

---

## Transforming between classes

Furthermore, a `ExplicitGroup` can be transformed into a `CayleyGroup` by the `.toCayleyGroup()` method. The only drawback is that the function that defined the `ExplicitGroup` is lost in the process.

```python
H = G.toCayleyGroup()   # H is now a CayleyGroup
```

The reverse method also exists.

```python
I = H.toExplicitGroup()   # I is now a ExplicitGroup
```

The principal advantage og the `ExplicitGroup` class is that it does not have to store the entire operation table in memory, but only the elements and the function that defined it.

> As the function that defined the `ExplicitGroup` is lost in the process of transforming it into a `CayleyGroup`, we do not recommend converting between classes very often. This can result in a significant loss of performance time.
